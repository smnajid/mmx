# Tech stack

## Backend
- Java **25** (`java.version` in `backend/pom.xml`), Spring Boot **4.0.5** (starter parent BOM; manages JUnit 5, AssertJ, Mockito, Testcontainers).
- Maven reactor root: `backend/pom.xml` (no pom at repo top). ArchUnit **1.4.2**.
- Persistence: JPA + PostgreSQL (Testcontainers for `integration`), Flyway migrations in `mmx-bootstrap/src/main/resources/db/migration/V*.sql`.
- Messaging: Kafka (outbox pattern, `e2e` tests use broker container).
- OpenAPI Generator runs per-spec (002–006) in `mmx-adapter-in-rest/pom.xml` → `target/generated-sources/` (not committed; packages `generated.model`, `generated.settings`, `generated.grants`, …).
- Surefire `groups`/`excludedGroups` properties passthrough for JUnit tag expressions (`-Dgroups=fast` etc.); empty default runs all.

## Frontend
- Angular **21.2**, TypeScript **5.9**, Node **22** (`.nvmrc`), npm pinned `npm@10.9.7` (packageManager).
- Unit tests: Vitest via `ng test` (jsdom); e2e: Cypress 15.
- Codegen: `openapi-typescript` from `contracts/` → `src/app/core/api/generated/` + widget `projects/order-creation-widget/src/lib/generated/` (regenerated by `pre*` hooks).
- Widget lib built with ng-packagr (`npm run build:widget`). Prettier 3.8 available (no dedicated script).

## Tooling / governance
- OpenSpec CLI for spec-driven work (`openspec validate`, `openspec status --json`); config `openspec/config.yaml`.
- Serena LSP active for java + typescript.
